# Leon Xu — Personal Academic Website

Static academic website for Liang (Leon) Xu, Associate Professor of Operations Management at Singapore Management University.

Site source: HTML/CSS, built and deployed through GitHub Pages Actions. The CV PDF is compiled from LaTeX during deployment.

Pages: Home, Research, Teaching, CV.

Live homepage (GitHub Pages user site): https://xuliang-leon.github.io/

To publish: Settings → Pages → Build and deployment → Source: GitHub Actions.
